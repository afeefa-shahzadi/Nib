# Mycelium MVP Scope

## Objective
Define the smallest meaningful version of Mycelium that demonstrates the product thesis while remaining buildable with a focused early-stage team.

## MVP Goals
- Prove the structured content object model.
- Prove adaptive reading modes.
- Prove archive relationships and lineage visibility.
- Prove at least one monetized derivative flow.

## Included in MVP
- Authenticated creator workspace.
- Structured editor with a limited set of block types.
- Reader mode switching for at least three modes.
- Content graph view for related items.
- Branch creation and display.
- Public and premium visibility states.
- Membership gating for at least one branch type.
- Basic analytics dashboard.

## Excluded from MVP
- Full team collaboration suite.
- Advanced AI generation.
- Native mobile apps.
- Extensive API ecosystem.
- Enterprise-grade workflow automation.
- Deep LMS feature set.

## Recommended MVP Team
- Product/design lead.
- Frontend engineer.
- Backend engineer.
- Part-time content strategist or editorial advisor.
