# Mycelium Open Questions

## Product Questions
- Should the first release focus more on writers or educators?
- Should debate mode be part of the MVP or a later differentiator?
- How much transformation should be creator-controlled versus automatic?
- What is the canonical default reading mode for public visitors?

## Business Questions
- Is the platform best launched as a premium SaaS, creator membership platform, or invite-only studio tool?
- Should monetization start with subscriptions or bundles?
- What adoption wedge is strongest: blogging, teaching, or knowledge commerce?

## UX Questions
- How should mode switching be explained to first-time readers?
- How much graph complexity is helpful before it becomes intimidating?
- How should branches be shown without making the reading experience feel fragmented?

## Technical Questions
- Should graph relationships be fully relational at first or backed by a specialized graph store later?
- What event model is needed to measure comprehension-oriented analytics responsibly?
- How should structured content transformations be implemented without losing editorial control?
